# Clustering

0. Initialize K-means: function that initializes cluster centroids for K-means

1. K-means: a function that performs K-means on a dataset

2. Variance: a function that calculates the total intra-cluster variance.

3. Optimize k: function that tests the optimum number of clusters by variance.

4. Initialize GMM: function initializes variables for a Gaussian Mixture Model

5. PDF: a calculates the probability density function of Gaussian distribution

6. Expectation: a function that calculates the expectation step in GMM.

7. Maximization: a function that calculates the maximization step in GMM.
