# Databases

0. Create a database: a script that creates the database db_0 in your MySQL server.

1. First table: a script that creates a table called first_table.

2. List all in table: a script that lists all rows of the table first_table in your MySQL server.

3. First add: a script that inserts a new row in the table first_table in your MySQL server.

4. Select the best: a script that lists all records with a score >= 10 in the table.

5. Average: a script that computes the score average of all records in the table.

6. Temperatures #0:  a script that displays the average temperature (Fahrenheit).

7. Temperatures #2: a script that displays the max temperature of each state (ordered by State name).

8. Genre ID by show: a script that lists all shows that have at least one genre linked.

9. No genre: a script that lists all shows without a genre linked.

10. Number of shows by genre: a script that lists all genres and displays the number of shows linked to each.
